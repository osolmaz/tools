# Agents moved to OnurPi

The personal agent instructions, skills, and synchronization scripts moved to [`packages/agents` in OnurPi](https://github.com/osolmaz/onurpi/tree/main/packages/agents).

Use these commands from an OnurPi checkout:

```bash
npm run agents:sync-simpledoc
npm run agents:sync
```

This directory remains only as a migration notice. Do not add agent resources here.
